usage: archive-scout [-h]
                     {run,status,search,results,errors,ai-review,research,research-index,init}
                     ...

Archive Scout automation CLI

positional arguments:
  {run,status,search,results,errors,ai-review,research,research-index,init}
    run                 Run or resume an Archive Scout operation
    status              Read project/queue status without modifying it
    search              Read-only Research Intelligence search
    results             Read deterministic scan results
    errors              Read errors and site issues
    ai-review           Run AI relevance review for deterministic report
                        matches
    research            Search the evidence index, optionally with grounded AI
                        synthesis
    research-index      Build/refresh the local Research Intelligence index
    init                Create project.json without opening the GUI

options:
  -h, --help            show this help message and exit
